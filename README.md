# 🎮 HUB Steam Manager

تطبيق سطح مكتب احترافي مبني باستخدام **Electron** لإدارة ألعاب Steam، يتيح لك استعراض وتصفح الألعاب بسلاسة، وحقن ملفات التجاوز والإدارة مباشرة في مسار التثبيت بخطوات بسيطة.

---

## ✨ المميزات الرئيسية
- **⚡ ربط مباشر بمكتبة ستيم:** فتح وحقن الألعاب مباشرة في مكتبة Steam الرسمية باستخدام الـ `AppID` عبر آلية **OpenSteamTool** (إنشاء ملفات `appmanifest` وتعديل ملفات الـ Lua).
- **🔍 الفحص التلقائي لألعاب ستيم:** فحص الأقراص في حاسوبك تلقائياً لاكتشاف ألعاب ستيم المثبتة وجلب تفاصيلها.
- **🧩 متصفح مودات متعدد المصادر:** دعم متكامل لتصفح المودات من Nexus Mods و Modrinth و UltraPlus.
- **🌐 تحميل باتشات الأونلاين (Online-Fix):** متصفح مدمج داخل التطبيق لتحميل باتشات اللعب الجماعي مع إدارة كلمات المرور تلقائياً.
- **🔄 التحديثات التلقائية:** دعم كامل للتحديث التلقائي (Auto-Updates) عبر GitHub لضمان حصول المستخدمين دائماً على أحدث إصدار.

## 🚀 طريقة التثبيت والاستخدام

1. توجه إلى قسم [Releases](../../releases) في المستودع.
2. قم بتحميل أحدث ملف تثبيت بصيغة Setup (`.exe`).
3. شغّل الملف على جهازك واتبع خطوات التثبيت القياسية وسيظهر الاختصار على سطح المكتب.
